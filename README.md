# iPhone Duo Demo

An independent, unofficial folding-phone concept landing page with a white studio theme and a scroll-controlled exploded product animation.

## Preview locally

Serve this folder with any static HTTP server, then open its local address. For example, `python -m http.server 8000`.

The page uses HTML, CSS, JavaScript, Lenis and GSAP. Product animation frames are in `frames/focus/`, with smaller mobile versions in `frames/mobile/`; the source video is in `assets/`. No build step is required. The animation libraries are loaded from jsDelivr.

## Publishing

GitHub Pages serves the repository's `main` branch from its root directory. All site asset paths are relative so they work under the repository's Pages URL.
